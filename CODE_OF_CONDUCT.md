# Code of Conduct

PHPFlow aims to be a useful, technically rigorous and welcoming open-source project.

## Expected behavior

When participating in issues, pull requests, reviews or discussions:

- focus criticism on code, behavior and technical trade-offs rather than people;
- assume good faith while still being precise about evidence and reproducibility;
- respect different experience levels and communication styles;
- keep reports free of credentials, private customer data and proprietary source code;
- accept maintainer decisions about project scope even when a proposal is not adopted.

## Unacceptable behavior

Harassment, personal attacks, discriminatory language, threats, deliberate disruption, spam and
publication of another person's private information are not acceptable.

## Enforcement

Maintainers may edit, hide, lock or remove contributions that violate these expectations and may
restrict participation when necessary.

If a conduct issue involves sensitive information, use GitHub's private reporting or moderation
features where available rather than posting the details publicly.

This code of conduct applies to project spaces maintained for PHPFlow.
